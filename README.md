## Jeopardy

Simple browser quiz game using HTML, CSS, and JavaScript.

## Features:
- Title, category, question, and answer inputs.
- Real-time score tracking for 3 teams with automated winner determination at game completion.
- Attach image URLs directly into question modals for visual prompts.
- Single-click board clearing to quickly start fresh trivia rounds.

## Files :
- index.html
- script.js
- style.css

## Run:
Open the Github Pages link found in the About section or the release.
